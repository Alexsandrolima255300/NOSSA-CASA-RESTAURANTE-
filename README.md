# Nossa Casa Restaurante

Site institucional responsivo do Nossa Casa Restaurante, em Uberaba–MG.

## Tecnologias
- HTML, CSS e JavaScript puro
- Layout responsivo para celular, tablet e computador
- Links de pedido e contato pelo WhatsApp
- Atalho para localização no Google Maps

## Publicação
O projeto pode ser publicado como site estático na Vercel ou no GitHub Pages. O arquivo inicial é `index.html`.
